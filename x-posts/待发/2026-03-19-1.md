AI agent 能收消息，但死活不回复。

排查了一小时。WebSocket 连接正常，消息确实到了 agent 手里，agent 也跑了推理——最后一步发回复，报了个 `getaddrinfo ENOTFOUND open.feishu.cn`。

DNS 炸了？不对，`dig @8.8.8.8 open.feishu.cn` 能解析。

真相：VPN 的 DNS 分流把 `open.feishu.cn` 吞了。WebSocket 走的另一条 DNS 链路，所以收消息没问题；HTTP API 回复走了本机 DNS，直接挂。

半边通半边断，这种 bug 最恶心。表面看"bot 不回复"，根因是网络层的 DNS 分流策略。

调 AI agent 最坑的不是模型，是基础设施。
