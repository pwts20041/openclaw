同一台 Mac 跑两个 AI agent 实例，偷懒把主实例配置直接复制给第二个。

结果级联翻车：

1. agent 列表串了 → 读别人的 workspace 报 EACCES
2. 飞书 bot 凭证串了 → 消息发到错误的 bot
3. workspace 路径串了 → 文件全找不到
4. JSON 配置改来改去改坏了 → 语法错误启动不了

修了三轮才意识到：问题不是哪里配错了，是"同步配置"这个思路就错了。

多实例同机的铁律：每个实例必须独立配置，共享只会带来级联故障。省 5 分钟，赔 2 小时。
