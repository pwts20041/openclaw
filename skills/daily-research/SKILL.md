# daily-research SKILL

## 用途

每日赚钱研究 + 工作日报，写入飞书文档。每天 22:20 自动触发。

## 执行步骤

### 1. 读取今日记忆

从 `memory/YYYY-MM-DD.md`（今天）读取工作事项，整理当日工作汇总。

### 2. 赚钱研究

使用 `web_search` 搜索以下维度：

- AI副业 / 内容变现最新动态（知乎盐选、小红书、公众号、X）
- 今日拐爷项目进展：OpenClaw PR、ai-shifu 运维、课程内容
- 可落地的新赚钱机会（优先结合拐爷已有资产：知乎作者、公众号、X账号）

### 3. 写入飞书文档

- 飞书文档 token：`CwXndCmLCotulfxfBxwcFMxDnrg`（每日赚钱研究+工作日报，创建于 2026-03-18）
- 追加当日内容（append），格式：

```
# YYYY-MM-DD 日报

## 今日工作

（工作事项要点）

## 赚钱研究

（今日发现的机会/趋势，3-5条，带行动建议）

## 明日计划

（1-3条最重要的事）
```

### 4. 汇报

输出不超过 300 字的汇报给用户。

## 注意

- 飞书 doc token 需要拐爷确认，默认用上方 token，没有则先创建新文档并记录 token 到本 SKILL.md。
- 不要重复写已经写过的日期内容，先 read 文档最后部分确认。
